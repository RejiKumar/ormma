# Incident Runbook (short)

- Contain: identify affected parentId/callSid, stop dispatch if needed.
- Assess: check logs for ids/statuses only (no transcripts/health values).
- Notify: follow pilot contacts.
- Mitigate: revoke consent or disable calls as appropriate.
- Document: record actions in docs/DECISIONS.md (ids only).
- Review: post-incident notes.
