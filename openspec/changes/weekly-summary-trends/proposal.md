# Proposal: Weekly summary and trend flags

## Why
Need deterministic trend flagging for BP and sugar (7-day vs previous 7-day, configurable threshold, no AI judgement) and a weekly summary generated by Haiku from numbers computed by code with a template fallback, scheduled weekly, delivered via FCM, shown in app with "Share with doctor" exporting text/PDF.

## What Changes
- Config: thresholds document (read-only config) reviewed by doctor advisor.
- Compute weekly stats (taken/missed counts, BP/sugar averages, symptoms) in code.
- Trend flagging: compare averages, raise flags if increase above threshold; store flags.
- Weekly summary: call claude-haiku-5-5 with structured numbers (model must not calculate), 5-8 lines, no advice/judgement, end with "Please share with the doctor if you have concerns."; on failure use template built from numbers.
- Schedule weekly (e.g. Sunday), send via FCM to members, show in app with "Share with doctor" (text/PDF).
- Add disclaimer where shown.

## Spec changes
- `trend-flagging`: ADDED configurable threshold config requirement and deterministic computation details.
- `weekly-summary`: ADDED scheduling/delivery and "Share with doctor" requirement.

## Impact
Uses Haiku 5.5 from functions; secrets for API key; FCM; mobile share/export.
